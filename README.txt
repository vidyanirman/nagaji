VIDYA NIRMAN — INSTALL APP PWA PATCH

Included:
- index.html (your supplied homepage with Install App button)
- manifest.webmanifest
- install.js
- sw.js
- icons/

INSTALL:
1. Extract this ZIP.
2. Upload/replace index.html in the SAME folder as your existing website homepage.
3. Upload manifest.webmanifest, install.js, sw.js and the icons folder into that same folder (site root).
4. Keep all your existing site pages, logo.png, CSS/assets, and other files. This ZIP only includes the homepage plus PWA files; it is not a replacement for your whole website.
5. Deploy/push the files to https://vidyanirman.online and open the HTTPS site in Chrome.
6. Reload once or twice. The Install App button appears when Chrome says the site is installable. Chrome may also show an install icon in the address bar/menu.

NOTES:
- PWA installation requires HTTPS (your domain should already use HTTPS).
- On iPhone/iPad, open in Safari > Share > Add to Home Screen.
- The app shell can fall back to the cached homepage when offline, but lesson pages, PDFs, external fonts/CDNs and AI require internet unless separately cached.
- If a student does not see the button, use Chrome's menu and check browser install eligibility. The browser controls when the native install prompt is available.
